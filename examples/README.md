# Примеры Okkama

Выберите формат задачи:

| Каталог | Что внутри | С чего начать |
|---|---|---|
| [Галерея](gallery/README.md) | 24 самостоятельных программы по задачам Rakupp: фракталы, парсеры, числа, алгоритмы, текст, параллельность и TCP. Рядом `dirstat`, пять веб-сценариев и статические диагностики | `./examples/gallery/run quicksort` |
| [Кукбук и приложения](cookbook/README.md) | Почтовый клиент, таксопарк, зарплата, конвертеры форматов, документация, чат, тесты и 158 лабораторий stdlib | `./examples/cookbook/run payroll demo` |
| [Блог](cookbook/web/blog/README.md) | Отдельное веб-приложение с лентой, формой, JSON API и SQLite | `./examples/cookbook/web/blog/run /tmp/blog.sqlite 8082` |
| [Книжный магазин](cookbook/web/bookstore/README.md) | Отдельное веб-приложение с каталогом, остатками, покупками и историей заказов | `./examples/cookbook/web/bookstore/run /tmp/books.sqlite 8081` |
| [Серверные примеры](web/README.md) | Небольшие HTTP-приложения и варианты организации серверного кода | Начните с README каталога |

Команды выполняются из корня репозитория. Launcher выбирает stdlib этого checkout и Perl проекта. В исходниках галереи и кукбука есть назначение программы и инструкция запуска.

Практическое объяснение модулей и задач: [книга stdlib](../docs/Okkama-Stdlib-RU.md). Правила языка: [книга Okkama](../docs/OkkamaBook-RU.md).

[Преобразования примитивов](primitive-casts.ok): одиночные `T(value)` и массивы
`@T(...)`, включая пустые и одноэлементные. Запуск из корня:
`OKKAMA_STDLIB_DIR=std ./okkama-pl/okkama examples/primitive-casts.ok`.

[Распаковка массивов](array-spread.ok): `@byte(nums...)`, смешанные аргументы
вывод типа у вариадического конструктора, включая пустой массив, и
`out <- @string(1, 2, 3)... <- endl` для записи результата выражения.
Правила описаны в [руководстве](../docs/array-spread.md).

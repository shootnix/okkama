# Лаборатории stdlib

158 полных программ по рецептам [книги](../../docs/Okkama-Stdlib-RU.md). У каждой программы собственный файл с документацией и команда запуска. Launcher сам включает тестовый режим для test-примеров.

Запускайте из корня репозитория. Интерактивные программы читают stdin, серверы ожидают подключения, сетевые клиенты используют адреса и окружение из соответствующего раздела книги. Перед запуском прочитайте заголовок исходника и условия рецепта.

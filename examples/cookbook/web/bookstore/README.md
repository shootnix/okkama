# Книжный магазин — отдельное веб-приложение

Каталог с остатками, покупка в браузере и история заказов. Сервер, HTML и JSON API написаны на Okkama. SQLite сохраняет состояние между перезапусками.

## Запуск

Из корня репозитория:

```sh
./examples/cookbook/web/bookstore/run /tmp/bookstore.sqlite 8081
```

Откройте [магазин](http://127.0.0.1:8081/). В новой базе появятся две книги. Нажмите «Купить»: приложение оформит заказ, обновит остаток и перезагрузит каталог. Ссылка «Заказы» показывает сохранённые заказы в JSON. Завершение — `Ctrl+C`. Повторный запуск с тем же файлом сохраняет заказы и остатки.

Можно использовать общий launcher:

```sh
./examples/cookbook/run web-bookstore /tmp/bookstore.sqlite 8081
```

Первый аргумент — путь к SQLite-файлу; родительский каталог должен существовать. Второй — порт, по умолчанию `8081`; `0` выбирает свободный. Строка `PORT N` сообщает фактический порт. Сервер слушает `127.0.0.1`.

## Маршруты и пример API

| Метод | Путь | Результат |
|---|---|---|
| GET | `/` | HTML-каталог и кнопки покупки |
| GET | `/api/books` | Каталог с `id`, `title`, `price_cents`, `stock` |
| GET | `/api/orders` | История заказов с количеством, суммой и временем |
| POST | `/api/orders` | Оформление заказа |

```sh
curl http://127.0.0.1:8081/api/books
curl -X POST http://127.0.0.1:8081/api/orders \
  -H 'Content-Type: application/json' -d '{"book":1,"quantity":2}'
curl http://127.0.0.1:8081/api/orders
```

Успешная покупка возвращает `201` и JSON с `book`, `quantity`, `total_cents`. Для первой книги две штуки стоят `6400` центов. Недостаточный остаток даёт `409`, неизвестная книга — `404`, недопустимое количество — `422`. Списание и запись заказа выполняются в одной immediate-транзакции; неуспешная покупка откатывается.

## Как устроен код

- [main.ok](main.ok) — создание хранилища, таблиц, маршрутов и HTTP-сервера.
- [model.ok](model.ok) — `BookShelf`, SQL, транзакция покупки и предметные проверки.
- [pages.ok](pages.ok) — `StorePages`, HTML и JSON-обработчики. Браузерный JavaScript вызывает API.
- [run](run) — запуск из любой рабочей папки с `std` текущего checkout.
- [CLI](../../apps/bookstore.ok) — управление той же базой из терминала.

Цены хранятся целыми центами. SQL-параметры передаются отдельно; HTML-названия экранируются. Владельцы соединений и транзакций закрываются через `defer`.

## Проверка

```sh
./examples/cookbook/run verify
```

Проверяются запуск самостоятельного приложения, HTML, покупка, отказ при недостаточном остатке, откат и история заказов. Общий каталог: [учебные программы](../../README.md).

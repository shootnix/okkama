# Блог — отдельное веб-приложение

Лента публикаций, отдельная страница записи, форма создания и JSON API. Сервер, страницы и постоянное SQLite-хранилище реализованы на Okkama.

## Запуск

Из корня репозитория:

```sh
./examples/cookbook/web/blog/run /tmp/blog.sqlite 8082
```

Откройте [блог](http://127.0.0.1:8082/). Заполните заголовок и текст, нажмите «Опубликовать». Новая запись появится первой в ленте; заголовок ведёт на отдельную страницу. После перезапуска с тем же файлом записи сохраняются. Завершение — `Ctrl+C`.

Альтернативный запуск:

```sh
./examples/cookbook/run web-blog /tmp/blog.sqlite 8082
```

Таблицы создаются автоматически. Первый аргумент — путь к SQLite-файлу в существующем каталоге, второй — порт (по умолчанию `8082`). Значение `0` выбирает свободный порт; сервер печатает `PORT N` и слушает `127.0.0.1`.

## Маршруты и пример API

| Метод | Путь | Результат |
|---|---|---|
| GET | `/` | Лента и форма публикации |
| GET | `/posts/:id` | Полный текст записи |
| GET | `/api/posts` | JSON-лента с `id`, `title`, `body`, `created_at` |
| POST | `/api/posts` | Сохранение записи |

```sh
curl -X POST http://127.0.0.1:8082/api/posts \
  -H 'Content-Type: application/json' \
  -d '{"title":"Первая запись","body":"Сегодня разбираемся со stdlib Okkama."}'
curl http://127.0.0.1:8082/api/posts
```

Публикация возвращает `201` и `{"status":"published"}`. Заголовок содержит 1–150 символов, текст — 1–20000; нарушение даёт `422`. Несуществующая запись возвращает `404`. Пользовательский HTML выводится как текст.

## Как устроен код

- [main.ok](main.ok) — создание базы, маршрутов и HTTP-сервера.
- [model.ok](model.ok) — неизменяемый `Draft`, его проверки и хранилище `BlogPosts`.
- [pages.ok](pages.ok) — `BlogPages`, HTML-лента, запись, форма и JSON API.
- [run](run) — запуск с библиотекой текущего checkout из любой папки.
- [CLI](../../apps/blog.ok) — публикация и чтение из терминала через ту же модель.

Форма отправляет JSON через `fetch`, после публикации обновляет ленту. SQL использует отдельные параметры, а каждый вызов хранилища владеет своим соединением и закрывает его через `defer`.

## Проверка

```sh
./examples/cookbook/run verify
```

Проверяются самостоятельный запуск, публикация по HTTP, экранирование HTML, проверка заголовка и сохранность записей между процессами. Общий каталог: [учебные программы](../../README.md).

# DirStat: куда ушло место

Утилита считает число обычных файлов и суммарные байты по расширениям, сортирует группы по размеру и печатает таблицу либо JSON.

```sh
./examples/gallery/run dirstat/dirstat examples/gallery
./examples/gallery/run dirstat/dirstat examples/gallery --top=5 --json
```

Без пути обрабатывается текущая рабочая папка; `--top=N` принимает 1..1000, по умолчанию 10. Путь можно передать до или после флагов. Расширение чувствительно к регистру, файлы без расширения попадают в `(none)`. Скрытые файлы и каталоги пропускаются; символические ссылки не обходятся. Максимальная глубина — 64.

В JSON поле `total_bytes` относится ко всем найденным файлам, даже когда `--top` сокращает список `kinds`.

- [dirstat.ok](dirstat.ok) — аргументы и представление результата.
- [lib/scan.ok](lib/scan.ok) — детерминированный обход `DirectoryEntries`, снимки `ScannedFile` с путём, расширением и размером.
- [lib/tally.ok](lib/tally.ok) — группировка через `OrderedSet`, суммирование снимков и предметный порядок `KindTotal`.

Сканирование создаёт значения; подсчёт работает только с этими значениями и повторно не читает метаданные. Рекурсивный результат объединяется преемником `ScannedFiles`. Конкретные файлы утилита не изменяет.

Проверка на временном каталоге:

```sh
./examples/gallery/run check --only dirstat/dirstat
```

Исходная задача: [Rakupp dirstat](https://github.com/ash/rakupp/tree/main/examples/dirstat). [Общая галерея](../README.md).

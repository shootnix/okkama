# Галерея Okkama: от фракталов до WebSocket

30 запускаемых программ по задачам из [каталога примеров Rakupp](https://github.com/ash/rakupp/tree/main/examples): **24 самостоятельных примера**, многомодульный `dirstat` и **пять веб-сценариев**. Рядом — десять небольших примеров статической диагностики Okkama.

Исходный каталог изучен на commit [`32d904e`](https://github.com/ash/rakupp/tree/32d904e314274191008910aa1ef402cdf5acb888/examples). Это самостоятельные реализации задач на Okkama. [catalog.json](catalog.json) связывает программы с исходными примерами и фиксирует состав изученного каталога. В каждом исходнике есть назначение, команда запуска и пояснение используемых приёмов.

## Запуск

Из корня репозитория:

```sh
./examples/gallery/run quicksort
./examples/gallery/run fibonacci
./examples/gallery/run calculator '2 * (3 + 4) - 5 / 2'
./examples/gallery/run brainfuck ',.' X
./examples/gallery/run modules/web/websocket-chat
```

Launcher использует `std` этого checkout и существующий `okkama-pl/okkama` с Perl 5.42.2. Можно вызывать launcher по абсолютному пути из другой папки. Путь, переданный `dirstat`, трактуется относительно вашей рабочей папки. `OKKAMA_GALLERY_DIR` launcher задаёт сам: веб-пример находит свои CSS и шаблон по этому пути.

Все 24 основных файла запускаются **без аргументов** и содержат собственные данные. Для них достаточно интерпретатора и stdlib текущего проекта. Сетевой `echo-server` сам создаёт сервер и клиент на свободном порту `127.0.0.1`; остальные основные программы работают локально без сокетов. Каждый запуск заканчивается сам.

Отдельный файл можно запускать напрямую из корня:

```sh
OKKAMA_STDLIB_DIR="$PWD/std" ./okkama-pl/okkama examples/gallery/matrix.ok
```

## Фракталы и клеточные автоматы

| Программа | Задача и результат | Что показывает Okkama |
|---|---|---|
| [mandel.ok](mandel.ok) | ASCII-множество Мандельброта, 75×30 символов, до 112 итераций на точку | `float`, отдельные координаты комплексного числа, преемник орбиты |
| [sierpinski.ok](sierpinski.ok) | 32 строки треугольника Серпинского шириной 63 символа | Rule 90, XOR, `map`, новый снимок строки |
| [life.ok](life.ok) | Восемь поколений glider на торе 12×8 | Двумерное значение, подсчёт соседей, переход к следующему полю |

`mandel` рисует ту же геометрию и палитру, что исходная задача; проверяющий скрипт сравнивает весь рисунок с независимым вычислением на Python. Для «Жизни» начальное поле фиксировано: повторные запуски позволяют сравнить поколения. В коде также проверяется период два у blinker.

```sh
./examples/gallery/run mandel
./examples/gallery/run sierpinski
./examples/gallery/run life
```

## Разбор текста и интерпретаторы

| Программа | Задача и результат | Как устроена |
|---|---|---|
| [calculator.ok](calculator.ok) | `1 + 2 * 3 = 7`, `(1 + 2) * 3 = 9`, `0.1 + 0.2 = 3/10` | Recursive descent с приоритетами; `ParseResult` содержит `rat` и следующую позицию |
| [json-tree.ok](json-tree.ok) | Дерево данных Voyager 1 и точное расстояние `1639/10` | `ParsedJson`, `Json`, `JsonKind`, обход объекта и массива, печать и повторный разбор |
| [rpn.ok](rpn.ok) | `3 4 + 5 * = 35`, `1 3 / = 1/3` | Неизменяемый стек и действия-преемники |
| [brainfuck.ok](brainfuck.ok) | `Hello World!` | Восемь инструкций, байтовая лента, таблица пар скобок и снимки машины |

Калькулятор принимает одно выражение аргументом. Числа с десятичной точкой разбираются в точные дроби; унарные `+`/`-`, скобки и левоассоциативное деление входят в пример. В RPN числа задаются целыми либо дробями вроде `1/3`, токены разделяются пробелами.

```sh
./examples/gallery/run calculator '8 / 4 / 2'
./examples/gallery/run calculator '0.1 + 0.2'
./examples/gallery/run rpn '1/3 3 *'
./examples/gallery/run brainfuck ',.' X
```

Brainfuck использует 64 байтовые ячейки с арифметикой по модулю 256. Пары скобок проверяются перед выполнением; есть предел 100000 шагов. `,` читает ASCII-вход из второго аргумента, после конца входа возвращает ноль. Выход за ленту отклоняется. Строка программы ограничена 4096 символами.

## Числа и математика

| Программа | Задача и проверяемый результат | Приёмы |
|---|---|---|
| [primes.ok](primes.ok) | Первые 20 простых, факториалы 10/25/50, числа Мерсенна, Коллатц | Делители до квадратного корня, `BigInt`, `reduce`, преемник состояния |
| [rationals.ok](rationals.ok) | Гармонические числа, `H₁₀ = 7381/2520`, приближение π `355/113` | Точные `rat`, цепная дробь и свёртки |
| [fibonacci.ok](fibonacci.ok) | Два алгоритма, сверка F(0)..F(30), полные F(100), F(250), F(500) | `BigInt`, быстрое удвоение, immutable-пара соседних чисел |
| [factorize.ok](factorize.ok) | `600851475143 = 71 * 839 * 1471 * 6857`, число делителей, НОД/НОК | Trial division, `Frequencies`, Евклид и `BigGcd`/`BigLcm` |
| [pascal.ok](pascal.ok) | 12 строк Паскаля, сверка строки 11 с C(11,k), нечётный рисунок | Новая строка через `map`, сохранение исходного треугольника |
| [matrix.ok](matrix.ok) | Произведение `[[58,64],[139,154]]`, транспонирование, единичная матрица, det = −10 | Вложенные `map`/`reduce`, проверка размеров |

В Okkama десятичный литерал относится к `float`. Точность в `rationals` выражена явно через `rat(1,10)`, а в калькуляторе десятичная запись превращается в дробь при разборе. Для больших целых используется `BigInt` с отдельными объектами арифметических операций.

```sh
./examples/gallery/run fibonacci
./examples/gallery/run factorize
./examples/gallery/run matrix
```

## Алгоритмы

| Программа | Задача и результат | Приёмы |
|---|---|---|
| [quicksort.ok](quicksort.ok) | Quicksort и merge sort совпадают со `Sorted`, включая дубликаты | Рекурсия, `filter`, соединение новых последовательностей |
| [hanoi.ok](hanoi.ok) | Четыре диска, полный план из 15 ходов | Рекурсия возвращает план; ход — отдельное значение |
| [nqueens.ok](nqueens.ok) | 92 расстановки для доски 8×8 и одна показанная доска | Backtracking, отдельные ветви с собственными снимками |

В алгоритмах нет скрытого изменяемого массива. Например, ветка поиска ферзей получает собственную расширенную последовательность, а обе половины сортировки возвращают свои результаты. Там, где удобно идти по шагам, конкретный объект объявляет `following() is ^Type`; прежний объект сохраняется.

## Текстовые задачи

| Программа | Задача и результат | Приёмы |
|---|---|---|
| [anagrams.ok](anagrams.ok) | 31 слово, десять классов анаграмм; самая большая группа содержит шесть слов | Канонический ключ, `OrderedSet`, `Sorted`, предметный `Comparing` |
| [wordcount.ok](wordcount.ok) | Частоты и ASCII-диаграмма: `the` — 10, `fog` — 6 | Regex-токены, `Frequencies`, порядок по убыванию частоты и затем по слову |
| [cipher.ok](cipher.ok) | ROT13, Цезарь и Виженер с обратным преобразованием | Латинские алфавиты, сохранение регистра, курсор ключа как значение |
| [roman.ok](roman.ok) | Римские числа 1..3999 туда и обратно | Таблица вычитательных форм и проверка канонической записи |

`cipher` — учебные классические преобразования: пример работает с латинскими буквами и сохраняет пробелы и знаки. Для Виженера позиция ключа продвигается только на буквах.

## Параллельность и IO

| Программа | Задача и результат | Приёмы |
|---|---|---|
| [parallel.ok](parallel.ok) | 168 простых ниже 1000; квадраты 1..12 через канал | Четыре диапазона, максимум два изолированных worker-процесса, `ParallelMapped`, `Channel` |
| [sleep-sort.ok](sleep-sort.ok) | Порядок пробуждения девяти задач с разными таймерами | Общий стартовый `Event`, `FutureGroup`, канал результатов |
| [echo-server.ok](echo-server.ok) | `hello → HELLO`, `okkama sockets → OKKAMA SOCKETS` | Реальный TCP, порт 0, байтовый префикс длины и точное чтение |

Результаты `ParallelMapped` возвращаются в порядке входных диапазонов, даже если workers завершаются иначе. Sleep sort показывает именно таймеры и планирование: проверяется сохранение всех чисел; для сортировки данных есть отдельный пример `quicksort`. TCP-пример читает длину и тело раздельно, поэтому границы сообщений не зависят от разбиения TCP на пакеты.

## Quine

[quine.ok](quine.ok) печатает **свой полный исходник, включая комментарии**, без чтения файлов. Шаблон вставляет собственное строковое представление через `JsonText`/`CompactJson`.

```sh
./examples/gallery/run quine > /tmp/okkama-quine.ok
cmp examples/gallery/quine.ok /tmp/okkama-quine.ok
```

## Утилита статистики каталога

[dirstat](dirstat/README.md) — небольшой многомодульный проект: обход отдельно от группировки и представления.

```sh
./examples/gallery/run dirstat/dirstat examples/gallery
./examples/gallery/run dirstat/dirstat --top=5 --json examples/gallery
```

## Веб-сценарии

[Веб-примеры](modules/web/README.md) соответствуют задачам Cro из исходного каталога. Каждый сам запускает loopback-сервер на свободном порту, выполняет запросы настоящим клиентом Okkama, проверяет ответы и закрывает ресурсы.

```sh
./examples/gallery/run modules/web/service
./examples/gallery/run modules/web/rest-api
./examples/gallery/run modules/web/forms
./examples/gallery/run modules/web/web-features
./examples/gallery/run modules/web/websocket-chat
```

Для веб-приложений с постоянной базой и интерфейсом браузера рядом есть [блог](../cookbook/web/blog/README.md), [книжный магазин](../cookbook/web/bookstore/README.md) и [чат](../cookbook/apps/chat.ok).

## Статические диагностики

[analysis](analysis/README.md) содержит десять намеренно ошибочных файлов. Проверка читает их анализатором, сопоставляет сообщения с ожидаемыми и **не выполняет `main`**. Это отдельная учебная коллекция ошибок объявлений, ролей, generic-контрактов и использования преемников.

```sh
./examples/gallery/run check --analysis-only
```

## Проверка галереи

```sh
./examples/gallery/run check
./examples/gallery/run check --skip-network
./examples/gallery/run check --only calculator
./examples/gallery/run check --only modules/web/forms
```

Скрипты используют Python 3.9+ из стандартной поставки и Perl проекта. `OKKAMA_GALLERY_ANALYZER_PERL` позволяет явно выбрать путь к Perl 5.42.2. Выборочная проверка отражается в отчёте; запуск без флагов проверяет полный набор.

Проверяются:

- Синтаксис, объявленные контракты и ожидаемые отказы всех `.ok`, включая помощников.
- Результаты 24 основных программ: независимые числовые и структурные проверки, весь рисунок Мандельброта, биномиальный рисунок Rule 90 и точное совпадение quine с исходником.
- `dirstat` на временных файлах: байты, число файлов, top, пустой каталог, скрытые имена и symlink.
- Пять веб-программ: HTTP, JSON, multipart, загрузки, middleware, статика, шаблон, streaming, SSE и WebSocket.
- Ошибки ввода калькуляторов и Brainfuck, точность десятичных вычислений и ввод символа в Brainfuck.

Результаты: [checks.json](checks.json), [analysis-checks.json](analysis-checks.json). Отчёты содержат состав проверки и SHA-256 исходников. Все прикладные программы выполняют собственные `confirm`; дополнительный checker сравнивает наблюдаемый результат с независимыми условиями.

Другие практические проекты и все рецепты stdlib: [кукбук](../cookbook/README.md), [книга stdlib](../../docs/Okkama-Stdlib-RU.md).

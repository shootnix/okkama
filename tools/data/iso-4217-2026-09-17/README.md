# Pinned current ISO currency/fund codes

Authoritative SIX ISO 4217 List One XML, published 2026-09-17. Exact downloaded
bytes are retained; SHA-256 and source URL live in manifest.json. Deduplication by
alphabetic code is permitted only if repeated minor-unit entries agree.
178 current codes: 139 with 2 minor-unit digits, 17 with 0, 7 with 3, 2 with 4,
13 with N.A. The latter are valid identities without an inferred precision.
Historical List Three and private/non-ISO codes are outside this snapshot.

CLDR names/symbols/patterns are a separate pinned 46.1.0 representation dataset;
an ISO code absent from that older CLDR snapshot falls back to its explicit code.
No exchange-rate or cash-rounding source is included.

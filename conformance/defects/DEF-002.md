# DEF-002 — Perl accepts an overloaded variadic action

- Implementation: okkama-perl at git f1ad6d43
- Case: `L03.variadic.overloaded`
- Contracts: `CALL.VARIADIC` (invalid), `CALL.OVERLOADS` (invalid)
- Authority: spec 11.8 "Variadic action overload sets remain forbidden"; spec 11.8.1 "an action with a
  variadic parameter cannot be overloaded in the current milestone"; LLM context 15 "Variadic names cannot
  be overloaded". (The grammar note "actions with a variadic parameter do not participate in action
  overloading" is compatible with forbidding the set.)
- Program: `total(values is ...int) is int` and `total(a is int) is int` on one object, then `Summer().total(1)`.
- Expected: rejection before or during execution; the program must not complete.
- Observed: the program completed with exit status 1 (the fixed overload was selected).
- Status: open. Expectation retained.

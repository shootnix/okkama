# DEF-002 — withdrawn

- Implementation: okkama-perl at git f1ad6d43
- Case: `L03.variadic.overloaded` (rewritten)
- Status: **withdrawn** (31.10.2026).

The record claimed that Perl wrongly accepts `total(values is ...int)` next to
`total(a is int)` and selects the fixed overload for `Summer().total(1)`. The language
owner then allowed variadic overloads (spec 11.8, 11.8.1): fixed and variadic signatures
of one name coexist, variadic signatures may differ by tail element type, and a call that
fits a fixed signature never selects a variadic one. Under that rule Perl's behaviour is
correct.

The case now expects the fixed overload for `total(1)` and the variadic one for
`total()` and `total(1, 2)`. The expectation changed because of an owner decision, not
to match Perl.

# DEF-012 — Perl accepts map literals with keys of different types

- Implementation: okkama-perl at git f1ad6d43
- Case: `L05.map.mixed-key-types-rejected`
- Contract: `COLL.MAP` (invalid)
- Authority: language owner decision of 21.10.2026 (D-047): a map has exactly one key type.
- Program: `let mixed = [1: "int", "1": "string"];`
- Expected: rejection, statically or when the literal is evaluated.
- Observed: the map is built with an `int` key and a `string` key; the program completes with status 0.
- Status: open.

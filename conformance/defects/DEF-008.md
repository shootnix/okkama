# DEF-008 — withdrawn

- Implementation: okkama-perl at git f1ad6d43
- Former case: `L04.fields.default-skipped-when-supplied` (removed)
- Status: **withdrawn** (19.10.2026).

The record claimed that Perl wrongly evaluates a field default when the constructor
supplies the field. The language owner then refined D-035: before the constructor runs,
`self` is filled with every default. The constructor then binds the supplied values,
replacing the defaults, and construction fails if any field is still unbound. Under that
rule Perl's behaviour is correct.

The case was rewritten as `L04.fields.default-evaluated-then-replaced`, which Perl
passes. The expectation changed because of an owner decision, not to match Perl.

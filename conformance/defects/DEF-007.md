# DEF-007 — Perl `%` uses floored instead of truncated division

- Implementation: okkama-perl at git f1ad6d43
- Case: `L02.int.modulo-sign`
- Contract: `VAL.INT-MODULO-SIGN`
- Authority: language owner decision of 19.10.2026 (D-031): `%` as in Go (sign of the dividend).
- Expected: `-7 % 3` = -1, `7 % -3` = 1.
- Observed: `-7 % 3` = 2, `7 % -3` = -2 (sign of the divisor, Perl's native `%`).

# DEF-005 — Perl int arithmetic is not exact beyond 64 bits

- Implementation: okkama-perl at git f1ad6d43
- Case: `L02.int.overflow-wraps`
- Contract: `VAL.INT-OVERFLOW`
- Authority: language owner decision R01 (OIR-1 §23, 20.10.2026; supersedes D-016 of 19.10.2026):
  `int` is an exact bigint.
- Expected: `MAX + 1` = 9223372036854775808, `MIN - 1` = -9223372036854775809, `MAX * 2` =
  18446744073709551614, `-MIN` = `MIN * -1` = 9223372036854775808, `MIN % -1` = 0.
- Observed: Perl represents only −2^63…2^64−1: `MAX + 1` is exact, but `MIN - 1` fails with
  `RuntimeError: Integer result cannot be represented exactly`.
- Status: open.

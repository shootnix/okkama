# DEF-001 — Perl parser rejects a trailing comma in constructor field shorthand

- Implementation: okkama-perl (okkama-pl), observed at git f1ad6d43
- Case: `L01.gram.constructor.shorthand-trailing-comma`
- Contract: `GRAM.CONSTRUCTOR-DECL` (boundary)
- Authority: `docs/okkama-grammar-1.0.ebnf`:
  `field_param_list = field_param ("," field_param)* trailing_comma? ;`
- Expected: `Pair(:a, :b,);` is accepted by the parser.
- Observed: `Parse error at ")": Expect ":" before constructor shorthand field.`
- Severity: low (syntax convenience), but it is a grammar deviation.
- Status: open. The normative test is retained; the expectation is not weakened.

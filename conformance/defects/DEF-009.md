# DEF-009 — Perl float text is not the shortest round-trip form

- Implementation: okkama-perl at git f1ad6d43
- Cases: `L02.float.text-shortest-round-trip`, `L02.float.text-exponent-and-zero`
- Contract: `VAL.FLOAT-TEXT`
- Authority: language owner decision of 19.10.2026 (D-032): float text is Go's
  `strconv.FormatFloat(x, 'g', -1, 64)`.
- Expected: `0.1 + 0.2` -> `0.30000000000000004`, `1.0 / 3.0` -> `0.3333333333333333`,
  `1000000.0` -> `1e+06`, `1234567.0` -> `1.234567e+06`, `0.0 * -1.0` -> `-0`.
- Observed: `0.3`, `0.333333333333333` (15 significant digits, which does not read back to the
  same float), `1000000`, `1234567`, `0` (sign of zero lost).
- Status: open.

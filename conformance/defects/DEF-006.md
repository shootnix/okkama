# DEF-006 — Perl keeps CR inside fenced raw strings

- Implementation: okkama-perl at git f1ad6d43
- Case: `L01.lex.crlf.raw-string-discards-cr`
- Contract: `LEX.CRLF` (boundary)
- Authority: language owner decision of 19.10.2026 (D-030): line endings as in Go, where carriage
  returns inside raw string literals are discarded.
- Program: a CRLF source with ```` ```a<CR><LF>b``` ````.
- Expected: value `a\nb`, length 3.
- Observed: value `a\r\nb`, length 4.
- Status: open (spec 4.2 also still says every character is retained).

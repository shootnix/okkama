# HTTP2 settings and internal frame foundation

Public Http2Settings(header_table,initial_window,frame_size,streams) is a bounded local receive advertisement: defaults 4096/65535/16384/100; table 0..1048576, window 0..2147483647, frame 16384..16777215, streams 0..65535. Zero table/window/stream capacity is meaningful. Local bounds deliberately do not describe arbitrary received peer settings.

Internal Http2SettingsWire emits network-order settings. Client profile adds ENABLE_PUSH=0; server profile omits that client-only setting. Wire constraints follow [RFC 9113 section 6.5.2](https://www.rfc-editor.org/rfc/rfc9113.html#section-6.5.2). Internal modules are implementation collaborators, not the stable public frame/HPACK API.

`http/internal/http2_frame` handles exact nine-byte headers, unsigned 24-bit length, opaque type/flags and 31-bit stream ID. Reserved stream bit is ignored on input and never emitted. Parsed headers reject payload length above the receive budget before payload acquisition. Canonical frame values require exact payload length. Unknown extension types/flags survive structural decoding; later connection state decides when they may be ignored.

Header rules check stream-zero requirements, known fixed sizes, SETTINGS ACK shape, minimum HEADERS priority fields and disabled push. Connection faults reject before payload waits. PRIORITY length faults have stream scope: the reader drains that bounded payload before raising, preserving the following frame's alignment. Payload rules validate padding and WINDOW_UPDATE increment; zero increment is connection scope on stream zero, stream scope otherwise. These are structural rules, not a complete stream state machine or HPACK decoder.

`http/internal/http2_reading::Http2FrameReading(AsyncReading[,maximum]).result()` owns one lazy memoized frame result and borrows transport. Header reads request only remaining header bytes; payload reads are bounded to 65536 per call and validated against remaining length. Each source read has its own one-child group; outer result supervision waits cancellation cleanup. It does not retain a completed-Future history proportional to short reads. Boundary EOF throws EndOfHttp2Frames; partial header/payload EOF is a connection protocol fault. Caller/session owns physical transport closure.

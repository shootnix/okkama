# Object Masks → Capabilities (`cap`)

Механизм переименован без изменения семантики. Актуальный контракт и примеры:
[Object Capabilities (`cap`) 0.0.1](object-caps-0.0.1-ru.md).

В объявлениях используйте `cap` вместо `mask`; получение представления и чтение
поля через `::` остаются прежними. `mask` больше не объявляет представление.
Исторические исследования R13–R14 и журналы аудитов сохраняют старую терминологию
и относятся к прежней версии интерпретатора.
